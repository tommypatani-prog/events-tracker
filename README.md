# Мероприятия — трекер

Сайт с календарём, телеграм-бот, который заносит мероприятия из пересланных
сообщений и отвечает на вопросы по базе, и напоминания по правилам.

```
public/index.html   календарь, список, карточки
public/login.html   форма входа
middleware.js       охранник: без пропуска страница не отдаётся
api/login.js        приём пароля, выдача куки
api/logout.js       выход
api/events.js       чтение и запись данных
api/telegram.js     вебхук бота: разбор сообщений, вопросы, кнопки
api/cron.js         напоминания, запускается раз в сутки
lib/auth.js         подпись пропуска
lib/db.js           работа с Supabase
lib/ai.js           разбор и ответы через Claude
lib/tg.js           Telegram Bot API
supabase.sql        схема базы
```

## Установка

### 1. Зависимости

```bash
npm install
```

### 2. База

Supabase → SQL Editor → New query → вставить `supabase.sql` → Run.

Два секрета лежат на разных страницах:

- `SUPABASE_URL` — **Settings → Data API**, строка «Project URL».
  Либо соберите из адресной строки: `dashboard/project/<ref>` → `https://<ref>.supabase.co`.
- `SUPABASE_SERVICE_KEY` — **Settings → API Keys**, вкладка «Legacy anon, service_role
  API keys», кнопка Reveal. Новый ключ `sb_secret_…` с вкладки «Publishable and secret»
  тоже подойдёт. Кнопку «Disable JWT-based API keys» не нажимайте.

### 3. Бот

1. В телеграме написать [@BotFather](https://t.me/BotFather) → `/newbot` → получить токен.
2. Узнать свой числовой id: [@userinfobot](https://t.me/userinfobot) → `/start`.

### 4. Переменные окружения

Скопировать `.env.example`, заполнить и добавить в Vercel
(**Settings → Environment Variables**, все три галочки окружений):

| Переменная | Что это |
|---|---|
| `SITE_PASSWORD` | пароль на вход в сайт — один для всех |
| `EDIT_PASSWORD` | админский пароль, открывает правки уже внутри сайта |
| `SESSION_SECRET` | случайная строка для подписи куки |
| `SUPABASE_URL` | адрес проекта Supabase |
| `SUPABASE_SERVICE_KEY` | ключ service_role |
| `ANTHROPIC_API_KEY` | ключ [console.anthropic.com](https://console.anthropic.com) |
| `TELEGRAM_BOT_TOKEN` | токен от BotFather |
| `TELEGRAM_WEBHOOK_SECRET` | случайная строка, ей телеграм подписывает запросы |
| `TG_ALLOWED_IDS` | ваши id через запятую — кто может писать боту |
| `SITE_URL` | адрес сайта, бот даёт на него ссылки |
| `CRON_SECRET` | случайная строка, ей Vercel подписывает запуск напоминаний |

Секреты генерировать так:

```bash
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
```

### 5. Деплой

```bash
npx vercel --prod
```

### 6. Подключить вебхук

Один раз после деплоя, подставив свои значения:

```bash
curl -X POST "https://api.telegram.org/bot<ТОКЕН>/setWebhook" \
  -H "content-type: application/json" \
  -d '{"url":"https://<ваш-домен>/api/telegram","secret_token":"<TELEGRAM_WEBHOOK_SECRET>","allowed_updates":["message","edited_message","callback_query"]}'
```

Проверить: `curl "https://api.telegram.org/bot<ТОКЕН>/getWebhookInfo"` — в ответе
должен быть ваш адрес и `pending_update_count: 0`.

Затем в телеграме написать боту `/start`.

## Как пользоваться ботом

**Занести мероприятие.** Переслать боту приглашение, анонс или переписку —
текстом, картинкой, PDF или текстовым файлом.
Бот разберёт текст, покажет карточку и кнопки «Занести» / «Не надо».
Если не хватает чего-то важного — сначала спросит (до трёх вопросов),
потом покажет карточку. `/отмена` — бросить черновик.

**Файлы.** PDF (программа, письмо) и картинки (афиша) бот читает сам —
даты, площадка и состав программы обычно точнее именно там. Файл уезжает
в закрытое хранилище Supabase и попадает в «Материалы» карточки; открыть его
можно только с сайта, по временной ссылке. Берёт до трёх файлов за сообщение
и до 18 МБ каждый. Голосовые, видео и .docx не читает.

**Спросить про базу.** «Что в сентябре?», «где ещё нет тем?»,
«сколько подтверждённых до конца года?», «кто ведёт форум в Екатеринбурге?»

**Напоминания.** `/напоминания` — список правил.
`/напоминание 7 темы участники` — за 7 дней до мероприятия написать, если
не заполнены темы или участники. `/удалить_напоминание 2` — убрать правило.
Поля: `темы`, `участники`, `шаг`, `материалы`, `держатель`.
Приходят раз в сутки в 09:00 по Москве (`vercel.json`, cron `0 6 * * *` UTC).

## Что стоит знать

- Бот ничего не заносит молча: любое мероприятие проходит через подтверждение
  кнопкой. Модель ошибается на относительных датах и городах-омонимах, и
  это дешевле поймать до записи, чем чистить базу потом.
- Дата пересланного сообщения передаётся модели как точка отсчёта, поэтому
  «в следующий четверг» считается от неё, а не от сегодняшнего дня.
- Правки на сайте сохраняются сами через 1,2 секунды после последнего
  изменения. Кнопка «Сохранить» остаётся для тех, кто любит нажимать.
- Резервных копий Supabase на бесплатном тарифе не делает — раз в неделю
  выгружайте таблицу `events` через Table Editor → Export.
